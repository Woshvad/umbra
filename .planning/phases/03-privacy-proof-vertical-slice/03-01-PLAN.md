|----------|-------------|
| desk → ledger (Daml Script `submit`) | Each desk submits under its OWN party authority; the ledger's signatory/observer rules are the disclosure boundary being proven. |
| query @T party → returned ACS slice | `query` returns ONLY contracts where `party` is a stakeholder — the return set IS the privacy assertion. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-03 | Information disclosure | `RoundStats` leaking contents (not just count) | mitigate | PRIV-02 assertion: desks `query @RoundStats` returns only `sealedOrderCount`; their `query @Order` of others returns []. |
| T-03-04 | Information disclosure | `Asset` holdings visible beyond owner+operator | mitigate | PRIV-04 assertion: each desk `query @Asset` returns only `owner == thatDesk`; operator sees all 5. |
