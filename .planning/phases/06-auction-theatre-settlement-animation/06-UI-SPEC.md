## Reconciliation Notes (comp ↔ spec ↔ CONTEXT)

These resolve every gap by faithfully following the comp; executors must not deviate.

1. **Fixture identity.** The comp's `support.js` seed (BLUEROCK Buy 10@101 · MERIDIAN Sell 8@99 · HALWARD Sell 5@100) clears at **100.00**, matched **10**, legs **A↔B 8@100** + **A↔C 2@100**, balances **A:10/4000 · B:12/1800 · C:13/1200**. This is identical to spec §4. **Pin these exact values everywhere** (CONTEXT "Specific Ideas"). The live app derives them from the solver `/solve-preview` + `/settle` responses, but they MUST equal these numbers.
2. **Two data planes (CONTEXT key decision).** Theatre / Solver-Agent / Settlement Operator actions (`close`, `solve-preview`, `settle`, `sealedOrderCount`, `clearingPrice`, `rationale`, `curve`) go through the **solver HTTP API :4000** via a new `web/src/solver.ts` — the browser never holds the Operator token. Desk view reads (orders, holdings, `TradeConfirmation`) and `Venue.SubmitOrder` go through the **JSON API :7575** per-party via the Phase-3 `createLedgerContext`. The comp's `support.js` simulates both planes locally; the live wiring replaces the simulation but keeps every pixel.
3. **Agent panel appears twice.** The comp renders a **dedicated 04 Agent view** (full rationale + competing-agents table) AND an inline "SOLVER-AGENT-00 COMPUTING…" beat inside 03 Theatre's reveal pane. Build both. The `agent:{verified,source}` badge (Claude vs deterministic-fallback, CONTEXT) is a NEW element not in the comp — render it as a mono 9px bordered tag adjacent to the `SOLVER-AGENT-00` label, styled exactly like the comp's existing `SELECTED` tag (line 374).
4. **Live solver-offline graceful state (CONTEXT).** If :4000 is down, Theatre/Agent/Settlement show a mono caption "SOLVER OFFLINE — START THE SERVICE ON :4000"; Privacy (Phase 3, JSON-API plane) still renders. This is a NEW state not in the comp — style it as the comp's waiting paragraphs (Inter 14px/1.6 opacity .65).
5. **Theatre is a dark inverted surface** (`#0A0A0A` bg, `#F4F1EA` text) — the 60/30/10 split inverts inside this `<main>` only (see Color §, Theatre row).
6. **Competing-agents table (comp 04, lines 404–411) is stretch §19** per CONTEXT "Deferred". Phase 6 renders ONLY the real `SOLVER-AGENT-00` row (rank-1, flame dot, flame-tint bg). Keep the table markup so the stretch rows drop in later, but do not fabricate AGENT-01/02 in the live build.
