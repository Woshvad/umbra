  `scripts/.operator-token`; REQUIRES `parties.json`, so it runs AFTER the ledger is up).
- `solver` — `cd solver && npm run dev` (Express :4000; reads `scripts/.operator-token`).
- `web` — `cd web && npm run dev` (Vite :5173, proxies `/v1`→:7575).
- `test` — `cd daml && daml test` (the Daml Script tests — DEMO-02; self-contained, no `daml start` needed).
- `verify-privacy` — `node scripts/verify-privacy.mjs` (live per-party `/v1/query` wire check; needs the
  ledger up + tokens minted).
- `clean` — remove build artifacts + per-boot ephemera: `daml/.daml/dist`, `daml/parties.json`,
  `web/src/tokens.json`, `scripts/.operator-token` (do NOT remove `node_modules` unless trivially safe;
  prefer a conservative clean that only drops gitignored per-boot files + the dist).
- `demo` (composite, the one-liner) — per 07-RESEARCH "document-the-flow + best-effort orchestration":
  the target FIRST prints the canonical 4-terminal manual flow (the always-works path) with a one-line
  note that it is the recommended path, then best-effort sequences what can be safely sequenced (e.g.
  background the ledger, poll for :7575 up, mint tokens, background solver + web, open the 3-up Privacy
  view at http://localhost:5173). Keep the orchestration honest and OS-portable — do not rely on brittle
  background-PID juggling as the documented contract; the manual flow IS the contract. If clean
  cross-platform backgrounding is awkward in `make`, have `demo` print the ordered manual steps and run
  only the trivially-safe parts (this is acceptable and explicitly chosen in 07-RESEARCH open-question 1).
- Make the FIRST target a `help` (or default) that lists the targets, so a bare `make` is self-documenting.

package.json (root, edit — currently only has `"tokens"`): add npm-script mirrors so a Windows stranger
(no `make`) runs the same commands via `npm run <target>`:
- `"ledger": "cd daml && daml start"`

- `"solver": "cd solver && npm run dev"`

flow's job). Do NOT add a root `demo` npm script that backgrounds processes (not portable); document the

Privacy invariant: NO target or script writes/copies the operator token or the Anthropic key anywhere
