<objective>
Two backend seams that make the AI decision auditable and shareable. TRUST-03: a `proof.ts` module that writes an immutable per-round decision proof bundle to `solver/proofs/<roundId>.json` at settle time (node:crypto sha256 hashes; the KEY and raw prompt NEVER included — store `systemPromptHash`), served read-only via `GET /round/:id/proof`. WOW-05: a `proofpack.ts` module that renders an on-brand HTML proof-pack (deck tokens) and spawns headless Chrome/Edge `--print-to-pdf`, exposed via `GET /round/:id/proof-pack.pdf` streaming the PDF as a download; a `window.print()`/HTML fallback if Chrome spawn fails.

Purpose: TRUST-03 turns "trust the recompute" into a first-class auditable artifact; WOW-05 lets a judge one-click download an on-brand proof-pack (clearing proof + per-desk receipts + finality record + AI decision bundle). TRUST-03 must precede WOW-05 (the proof-pack reads the bundle + brief).
Output: `writeProofBundle`/`readProofBundle`, the settle-time write, `renderProofPackHtml` + Chrome spawn, `GET /round/:id/proof` + `GET /round/:id/proof-pack.pdf`, and tests (Chrome mocked).
</objective>
