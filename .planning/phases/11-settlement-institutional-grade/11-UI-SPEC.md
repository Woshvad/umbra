# Phase 11 — UI Design Contract

> Visual and interaction contract for the Phase-11 NEW frontend surfaces. Generated by
> gsd-ui-researcher, verified by gsd-ui-checker. Every surface is BOUND to the binding
> design comp (`Umbra design/Umbra.dc.html` + `screenshots/`, CLAUDE.md rule #2) — this
> phase EXTENDS the established numbered-view system and its shipped token set; it does
> NOT introduce a new visual language.

**Phase surfaces covered:**
1. **VIZ-03 — `07 Network Topology`** (NEW view): three participant nodes each hosting one
   desk's order, the operator/synchronizer node, and the atomic settlement transaction
   spanning all nodes. Single-operator LocalNet ⇒ "demo-real", honestly badged.
2. **WOW-07 — Guest 4th desk via QR → mobile**: a QR block hosted on `03 Theatre`, and a
   mobile-first `/join` route reusing `OrderTicket` + the private `FillCard`; the guest
   submits ONE sealed bid and sees ONLY its own order/fill (structural per-party privacy).
   Dev pre-minted scoped token; production guest auth is OIDC (Phase 12) — labeled.
3. **Settlement deltas** (`05 Settlement`): Daml-Finance-style Batch/Instruction legs
   (allocate → approve → settle finality), optional netting, token-agnostic cash symbol,
   and the guest's own-fill after the atomic batch settle.

## Spacing Scale

The binding comp uses an established irregular literal set (already exposed in
`tailwind.config.ts`). New Phase-11 surfaces PREFER the 4-multiple canonical subset and
reuse an inherited comp literal ONLY to stay pixel-adjacent to a shipped neighbor view.

| Token | Value | Usage (Phase-11 new surfaces) |
|-------|-------|-------------------------------|
| xs | 4px | Icon/dot gaps, redaction-stripe insets |
| sm | 8px | Compact label→value gaps, tag padding (`3px 7px` inherited exception) |
| md | 16px | Default element spacing; **`/join` mobile page padding** |
| lg | 24px | Node-card padding, section gaps (matches Privacy column `24px`) |
| xl | 32px | Column/leg breaks |
| 2xl | 48px | **Desktop view horizontal padding** (`30px 48px …` main padding — the shipped view frame) |
| 3xl | 64px | Page-level bottom spacing |

**Exceptions (inherited from the binding comp — binding, do NOT "normalize"):** `9, 11,
14, 18, 22, 26, 30, 34, 42` px literals already in `tailwind.config.ts spacing{}`. New
surfaces reuse `30px 48px 64px` main padding and `24px 22px 26px` node-card padding to
match the shipped `PrivacyView`/`TimeMachineView` grid exactly.

**Mobile exception (`/join`):** horizontal page padding drops to **16px** (not 48px);
touch targets ≥ **44px** min height (the shipped `SEAL ORDER` button at `padding:18px` ≈
54px and the side toggle at `padding:13px` ≈ 44px already satisfy this — do not shrink).

## Color

60 / 30 / 10 split, transcribed from the binding comp. Values are already in
`tailwind.config.ts colors{}` — reuse the named tokens, never raw variants.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F4F1EA` paper | Page background, node-card fills, `/join` background, all light surfaces |
| Secondary (30%) | `#0A0A0A` ink | Every 1px border, all text, the dark inverted stage (Theatre QR host), the operator/synchronizer node fill, redaction stripes (`bg-redact`) |
| Accent (10%) | `#D6FB3C` lime | See reserved-for list — NEVER on topology nodes, QR modules, or honesty badges |
| Signal / destructive | `#E2231A` red | Atomic-settlement finality (edges + `AtomicStamp`), active nav rule, on-ledger reject/error text, the honesty-badge marker square (the "not-the-full-real-thing" grammar, matching `RECONSTRUCTED` T3) |

**Supporting tokens (inherited, book-side only):** `#2B3AF2` buy / `#FF3D9A` sell for
BUY/SELL side coloring on orders/fills (guest side included); `#FF6A1A` flame for the
solver-computing pulse (Theatre only). `#262626` redact is the stripe second-stop.

**Accent (lime) reserved for — explicit list this phase:**
- the clearing-price reveal / uniform-price money shot (unchanged, `PriceReveal`);
- the guest's OWN active column/panel tint on `/join` (`rgba(214,251,60,.10)` background —
  identical to `PrivacyView`'s active-desk highlight, signaling "this is you");
- the `▮ MATCHED` chart-legend swatch (unchanged).
- **NOT** used for: any topology node fill/edge, the QR code, the atomic-settle edges
  (those are red), or any honesty/demo-real badge.

**QR contrast rule (hard):** QR modules are ink `#0A0A0A` on a paper `#F4F1EA` quiet-zone
ONLY — never lime or red modules (scannability + palette fidelity).

## Surface Contracts (prescriptive)

### VIZ-03 — `07 Network Topology` (NEW view, sibling of `TimeMachineView`)

- **Chrome (verbatim shipped pattern):** `<main style="position:relative;padding:30px 48px
  64px;overflow:hidden">` → section marker (`font-mono text-13 font-semibold` `07` +
  `font-body text-11 uppercase opacity-55 .16em` label) → `bg-ink` 1px rule (`margin:12px 0
  0`) → `font-display text-54 font-bold` headline (`lineHeight:.96; letterSpacing:-.02em;
  margin:26px 0 30px`). Identical to `TimeMachineView` lines 484-499.
- **Honesty badge (HARD, directly under headline):** the established red-square tag grammar
  (mirrors `TimeMachine` `RECONSTRUCTED`): `font-mono text-9 uppercase .16em` with a 6px
  `#E2231A` square + `DEMO-REAL · SINGLE-OPERATOR LOCALNET`, and the one-line limitation
  sub-caption in `font-body text-13 opacity-70`. This badge is NON-REMOVABLE while nodes
  resolve to one participant.
- **Diagram (hand-rolled, no lib):** a CSS-grid of node cards + an SVG connector overlay.
  - 3 **participant node cards** (codes BLUEROCK/MERIDIAN/HALWARD — 4th `GUEST` card
    appears once a guest has joined). Each card: 1px ink border, paper fill, `24px 22px
    26px` padding; header = `ColumnHeader`-style code (`font-mono text-13 font-bold .16em`)
    + role; body = `ORDER RESIDENT` label + the order rendered as a **commitment /
    redaction stripe** (`bg-redact`, `NOT VISIBLE` mono-9) — cross-node, contents are the
    owner's alone (privacy is structural, reuse the redaction motif, never render a rival's
    contents). Each card carries a small `PARTICIPANT · {node-id-or-LOCALNET}` caption; if
    all map to one participant, the `SAME PARTICIPANT (LOCALNET)` demo-real caption shows.
  - 1 **operator / synchronizer node**: ink-filled (`#0A0A0A`) card with paper text
    (`OPERATOR · SYNCHRONIZER`), centered/top — the inverted-surface grammar reused from
    Theatre; it sees a COUNT, never contents (venue-blind, matching Privacy's venue spine).
  - **SVG connector edges** (1px ink idle): node → synchronizer. On settle, edges light
    `#E2231A` red and `AtomicStamp` ("1 TRANSACTION · ATOMIC") overlays the whole diagram —
    the SAME atomic-finality grammar as `05 Settlement`, signaling the tx spans every node.
- **Data plumbing:** party-hosting metadata via a new operator-plane solver endpoint
  (credential-free, like `getStageOffsets`); `SolverError 'OFFLINE'` → `OFFLINE_CAPTION`.
  LocalNet single-participant is the labeled fallback (all nodes → one id → demo-real
  caption). Live cross-node atomic settle = live-UAT item (built + locally demoable).
- **States:** loading (`READING NODE TOPOLOGY…`, `animate-umbra-pulse`) → empty (no round,
  the empty-state copy above) → resident (nodes host redacted orders, idle ink edges) →
  settled (red edges + `AtomicStamp`). Reduced-motion honored (instant, no draw-on).

### WOW-07 — Guest QR host (`03 Theatre`) + mobile `/join`

- **QR host block (Theatre):** a bordered block placed BELOW the dark stage on `03
  Theatre` (does NOT disturb the shipped countdown/reveal beat). Contents: heading `SCAN TO
  JOIN AS A 4TH DESK` (`font-body text-10 uppercase .16em opacity-55` sub-label grammar +
  a `font-display text-22`/mono heading), the QR (ink modules on paper quiet-zone, ~160px),
  the sub-caption, and the HARD honesty label (`DEV TOKEN — PRODUCTION GUEST AUTH IS OIDC
  (PHASE 12)`) in the red-square tag grammar. **No secret in the QR** — it encodes only the
  `/join` URL + round id; the guest token is pre-minted server-side and delivered to the
  `/join` page, never embedded in the QR payload.
- **QR generator (discretion):** recommended `qrcode.react` (MIT, SVG output → stylable
  ink-on-paper, `level="M"`), PENDING the plan-time package-legitimacy gate; honest zero-dep
  fallback = a hand-rolled SVG QR encoder. Either way: SVG (not `<img>`), ink `#0A0A0A`
  modules, paper `#F4F1EA` background + quiet zone, no external fetch.
- **`/join` mobile route (reuses `DeskView`/`OrderTicket` + `FillCard`):**
  - **Mobile-first layout:** single column, `max-width:480px`, page padding **16px**,
    centered. Responsive rule: below `640px` (Tailwind `sm`) this is the only layout; above
    it, still capped at 480px (it is a phone surface). Headline shrinks to `text-40`.
  - Minimal chrome: `UMBRA · GUEST` wordmark row + a `DESK D · GUEST` tag + the `/join`
    HARD honesty label. No full desktop `Header`/`Nav`.
  - Body: the guest headline `JOIN THE DARK.` → `OrderTicket` (side toggle BUY/SELL, qty,
    limit — reused verbatim, incl. the one-per-round lock + seal-wipe) with the CTA relabeled
    `SEAL GUEST ORDER`. The guest submits on its OWN scoped token (per-party plane, exactly
    like A/B/C — token never hardcoded in web source; delivered to `/join`, not in the QR).
  - After batch settle: the private `FillCard` (`YOUR FILL` / `Visible only to you`) shows
    ONLY the guest's own fill — structural per-party privacy identical to the desks. The
    guest can never see another desk's order or fill.
  - **COMP-01 path:** guest is seeded eligible on onboarding. If a submit hits an ineligible
    party, render the on-ledger reject VERBATIM (error copy above) — never a render-time
    guard.
  - Touch targets ≥ 44px; existing button paddings already satisfy — do not shrink.

### Settlement deltas — `05 Settlement` (`SettlementView` / `DvpLegs`)

- **Daml-Finance legs:** keep the shipped simultaneous-settle beat (single `rAF`
  `settleProgress` 0→1 driving ALL legs + balances together — atomicity = simultaneity;
  never sequence legs). Delta: relabel the sub-label to `Delivery vs Payment · Batch/Instruction
  · {N} instructions` and add the finality micro-grammar `ALLOCATED → APPROVED →
  SETTLED` (mono-9, opacity .6) — the Batch settle commit IS the finality signal.
- **Provenance tag (HARD honesty):** a mono-9 ink-border tag reading `CN TOKEN STANDARD (CIP-0056)`
  (real interface conformance) or `DAML-FINANCE-PATTERN (IN-REPO)` (faithful fallback layer), driven
  by data — never render the literal "Daml Finance" (the library is unsatisfiable on this LF-2.1 /
  SDK-3.4.11 stack per the RESEARCH RECONCILIATION; lines 149/233 superseded accordingly).
- **Netting (default ON):** a `NETTED ⇄ GROSS LEGS` mono tag toggle. NETTED renders one net
  instruction per (party, instrument); GROSS derives the per-leg legs (still available for
  the topology viz / receipts). Netting must visibly conserve cash + assets (balances
  table unchanged in totals).
- **Token-agnostic cash:** the cash arrow label reads `← {cash} {CASH_SYMBOL}` from the
  settlement data (instrument symbol), defaulting to `USDCx` for §4 — no hardcoded literal.
- **Guest own-fill on settle:** the operator aggregate legs/balances include `GUEST` (Desk
  D) when present; the guest sees only its own leg via `/join`'s `FillCard`. §4 stays
  single-buyer-shaped and MUST still render `$100.00` / A=10·B=8·C=2 (continuous canary).
